# Phase 8: Centralized Logging

## Overview
TaskFlow uses the ELK Stack (Elasticsearch, Logstash, and Kibana) for centralized log storage, processing, and visualization.

## Log Sources
1. Application logs: Structured JSONL logs generated by the Flask application.
2. Docker logs: Container logs collected from Docker JSON log files.
3. Kubernetes logs: TaskFlow pod logs exported using kubectl and indexed in Elasticsearch.

## Architecture
- Logstash reads application and Docker log files.
- Logstash processes events and forwards them to Elasticsearch.
- Kubernetes pod logs are exported and indexed through the Elasticsearch Bulk API.
- Kibana provides searchable log views and filtering.

## Elasticsearch
Index pattern: taskflow-logs-*

Source types:
- application
- docker_container
- kubernetes_pod

## Verification
- Application logs verified in Kibana Discover.
- Docker container logs verified in Kibana Discover.
- 77 Kubernetes log records successfully indexed and verified in Elasticsearch.

## Notes
Kubernetes logs in this implementation are collected through manual pod-log export and bulk indexing. Continuous Kubernetes log forwarding is not configured.
